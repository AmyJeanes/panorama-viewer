# Panorama Viewer

A static viewer for 360 panorama tours, built on [Photo Sphere Viewer](https://photo-sphere-viewer.js.org/) with no build step. It opens a library folder from your own computer, laid out as in [`FORMAT.md`](FORMAT.md). Libraries aren't part of this repository other than an example one.

## Using it

Open https://amyjeanes.github.io/panorama-viewer/ and choose the folder that holds `library.json`, or drop it on the page in Chrome and Edge. Open demo shows the example library instead. Files are read from disk, never uploaded. Chromium based browsers remember recent folders and load the panoramas quicker.

Drag or use the arrow keys to look, and the wheel or a pinch to zoom. Click an arrow, or press WASD, to walk. Tours without arrows get a thumbnail gallery. Other keys: F fullscreen, I details, M mouse look, G gallery.

## Making tiles

```
uv run tiles.py <image>.jpg <library>/<source folder>
```

This writes the tiles to `tiles/<image>/` in that folder and prints the panorama's `width`, `height` and `tiles` fields for its manifest.

## Running locally

```
npm ci
python -m http.server 8360 --bind 127.0.0.1
```

If there is a `data/` folder, it will be used as the library source automatically. You can use `?pick=1` to ignore it and pick a folder manually.

Use `?debug=1` to show the tile debug view. `examples/` is a library of test patterns, regenerated by `uv run examples/make.py`.

## Deployment

Pushes to `main` deploy to GitHub Pages (Settings > Pages > Source: GitHub Actions).

## Contributing

- Never commit or deploy library data other than `examples/`. Locally, `data/` is a gitignored link to a private library.
- Every data path goes through `source.url()`, so all three sources keep working: served `data/`, Chrome's folder handles through `sw.js`, and the `webkitdirectory` fallback.
